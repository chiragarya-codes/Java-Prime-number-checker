🚀 Prime Number Checker in Java
📌 About The Project

This is a simple Java program that checks whether a given number is Prime or Not Prime.

The main goal of this project is to strengthen core programming fundamentals like:

Loops

Conditional Statements

Boolean Logic

User Input Handling

This program was written completely from scratch to improve logical thinking and problem-solving skills.

🧠 What is a Prime Number?

A prime number is a number greater than 1 that has only two factors:

1

Itself

Examples:

2 ✅

3 ✅

5 ✅

4 ❌ (because it is divisible by 2)

💻 Technologies Used

Java

VS Code

Git & GitHub

📂 How The Program Works

Takes user input.

Uses a for loop to check divisibility.

Uses a boolean variable to track prime status.

Prints whether the number is Prime or Not Prime.

🎯 Purpose of This Project

Currently focusing on building strong fundamentals in Java and improving problem-solving skills step by step.


## ▶ How to Run the Program

1. Compile the program:
   javac Isprime.java

2. Run the program:
